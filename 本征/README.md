# 本征

> **内容都会过期。所以按寿命分层，渐进地加，到期就废。**

一本把治理体系抽象成方法论的书。从一套已运行的 AI 组织管理体系中抽出可迁移的规则工程方法：六个动作串成一条链，两条约束横切其上，四条不变量是删不掉的部分。

## 这本书是什么

一条主线，十五个篇位，顺序不能颠倒：

| 篇 | 标题 | 回答什么 |
|---|---|---|
| 00 | 体系全貌 | 六个动作怎么串成一条链；两条横切从哪切 |
| 01 | 为什么会烂 | 三种不报警的腐坏；为什么越完整烂得越快 |
| 02 | 四条不变量 | 哪四条删不掉；为什么是四条而不是五条 |
| 03 | 判与落 | 五层怎么判；四个执行点位怎么选 |
| 04 | 写 | 九问缺一问会怎样；什么算可重建 |
| 05 | 检 | 判据怎么才会红；红不了的东西算不算规矩 |
| 06 | 长 | 新领域从零长一套的七步 |
| 07 | 退 | 到期条件怎么定；谁有权叫停 |
| 08 | 裁 | 什么能换、什么不能换 |
| 09 | 渐进 | 什么时候开始；做到哪儿停 |
| 10 | 组织同构 | 透过 AI 组织看人类组织：同构在哪，差异在哪 |
| 11 | 三种产物 | 产品、质量、数据，各自崩在哪一环 |
| 12 | 对照 | 德鲁克、PMBOK、NPDP、Six Sigma、CMMI、OKR／KPI，各叫什么名字 |
| 13 | 入表 | 内部合格不等于外部认账：一本不归你管的账要什么形状 |
| 14 | 速查卡 | 一页纸，打印出来贴墙上 |

## 怎么读

- **想立刻用**：读 00 与 14。
- **想知道为什么**：读 01 与 02。
- **正在动手**：读 03 到 09。
- **要跟人解释**：读 10 到 12。
- **要看外部的尺子**：读 13。

书中那些具体形态——六个动作、五层落点、九问、七步——取自一套已运行过的体系，证明这条路走得通，不构成必须如此的规定。读时把三样东西分开：**骨架**（删掉专有名词仍成立的命题）、**筋**（机制之间的牵连）、**示例**（层数、条数、阈值，随自己的场景填）。
