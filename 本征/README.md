# 本征——一本把治理写成结构的书

**寿命分层、不变量与可重建**

![书封](book/cover.png)

> **内容都会过期。所以按寿命分层，渐进地加，到期就废。**
>
> 从一套已运行的 AI 组织管理体系中抽出可迁移的规则工程方法：六个动作串成一条链，两条约束横切其上，四条不变量是删不掉的部分。

## 这本书是什么

一条主线，十五个篇位，顺序不能颠倒：

| 篇 | 标题 | 回答什么 |
|---|---|---|
| 00 | 体系全貌 | 六个动作怎么串成一条链；两条横切从哪切 |
| 01 | 为什么会烂 | 三种不报警的腐坏；为什么越完整烂得越快 |
| 02 | 四条不变量 | 哪四条删不掉；为什么是四条而不是五条 |
| 03 | 判与落 | 五层怎么判；四个执行点位怎么选 |
| 04 | 写 | 九问缺一问会怎样；什么算可重建 |
| 05 | 检 | 判据怎么才会红；红不了的东西算不算规矩 |
| 06 | 长 | 新领域从零长一套的七步 |
| 07 | 退 | 到期条件怎么定；谁有权叫停 |
| 08 | 裁 | 什么能换、什么不能换 |
| 09 | 渐进 | 什么时候开始；做到哪儿停 |
| 10 | 组织同构 | 透过 AI 组织看人类组织：同构在哪，差异在哪 |
| 11 | 三种产物 | 产品、质量、数据，各自崩在哪一环 |
| 12 | 对照 | 德鲁克、PMBOK、NPDP、Six Sigma、CMMI、OKR／KPI，各叫什么名字 |
| 13 | 入表 | 内部合格不等于外部认账：一本不归你管的账要什么形状 |
| 14 | 速查卡 | 一页纸，打印出来贴墙上 |

书前另有版权页、序言、阅读指南，书后有结语与附录 A 术语表；与 15 篇正文合计 19 章。

## 怎么读

- **想立刻用**：读 00 与 14。
- **想知道为什么**：读 01 与 02。
- **正在动手**：读 03 到 09。
- **要跟人解释**：读 10 到 12。
- **要看外部的尺子**：读 13。

书中那些具体形态——六个动作、五层落点、九问、七步——取自一套已运行过的体系，证明这条路走得通，不构成必须如此的规定。读时把三样东西分开：**骨架**（删掉专有名词仍成立的命题）、**筋**（机制之间的牵连）、**示例**（层数、条数、阈值，随自己的场景填）。

## 篇幅与字数口径

- **57,084 字**（对外出版折算口径），19 章，8 张内联插图。
- 字数口径：**纯汉字数 ＋ 英文单词数 ＋ 数字串数**（55,459 ＋ 783 ＋ 842），图块与图注不计字。该口径与《我思故我写》《我写故我播》一致，由本地权威字数脚本复算，构建器与脚本同值。
- PDF：A4，116 页（封面 1 ＋ 正文 115）／184 条书签；HTML：单文件 309 KB，19 章／184 条目录／8 张内联图。
- 内容分家：**骨架**可迁移，**示例**随场景填——书中的层数、条数、阈值都是参数，不是规定。
