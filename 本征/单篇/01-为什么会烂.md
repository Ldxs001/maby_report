# 《本征》的方法论沉淀：为什么会烂——三种不报警的腐坏

> 内容不是「旧了才失效」，从写下的那一刻起就在腐坏。腐坏有三种形态：路径断掉（失忆）、同等重要的东西堆过带宽（膨胀）、多处副本各改各的（漂移）。三种都不报警，所以靠「更小心」防不住，只能靠结构。本篇只讲病灶，不讲药方；药方在 02 到 09。
>

## §1 引子：写过、找不到、不敢信

接手一摊陌生的活，第一周往往会遇到三件小事。

第一件：明明有人写过，翻了两小时没找到，最后重写了一遍。第二件：找到了三份，内容不一样，不知道哪份算数。第三件：一份很全的文档，从头读到尾，读到后面忘了前面，索性不读了。

三件事看起来是三种毛病：记性差、版本乱、文档长。往深一层看，它们是同一个东西的三个切面——**规则在传递过程中，以三种不同的方式失真，而且三种都不发出声音。**

这就是本篇要说的：腐坏不是「用久了变旧」，是**结构本身带的**。写下第一句话的时候，腐坏就已经开始了。

（这一节的场景是经验刻画，不是特定事件的记录。三种形态的判定标准见 §2 到 §4。）

## §2 腐坏一：失忆不是忘了，是路径断了

失忆有两种，价值完全不同。

**内容没了**：删了、丢了、覆盖了。这种好办——知道丢了什么，重写就行。

**路径没了**：内容还在，但没人知道它在哪，或者不知道该找它。这种难办，因为**当事人不知道自己丢了东西**。

在这套体系的记录里，多数「找不到」属于第二种。记录只增不减，检索能力却不变。加到某个量级之后，每一份都还在，但从「能找」变成「碰运气」（经验刻画 [3]）。

一个具体的机制：**索引比内容烂得快。**（机制性推断：内容可以三年不动，指向它的路径换一次人就断一次；说的是两者的耐久差，不是说内容不会过时。） 内容写下来可以三年不动，指向它的那条路径——标题、目录、命名、口头交接——换一次人就断一次。索引断了，内容再多也等于不存在。

判据只有一条：**一个没参与的人，在有限步数内能不能定位到它？** 说得出「在哪一类、叫什么、从哪进」，算找到；只能说「我记得在某处写过」，不算路径，算记忆。

失忆的隐蔽处在这里：它不产生错误，只产生重复。重写一遍的那份，往往比原来那份更差——因为写的人不知道原来那份里有哪些坑已经踩过。

## §3 腐坏二：膨胀不是变多，是同等重要

带宽是硬的。超过的那部分不进决策，直接丢。

人的短时记忆一次能同时处理的单元在四个左右 [1]；模型的上下文窗口看起来很大，但放在中间位置的信息利用率低于首尾 [2]。数字不同，性质一样：**一次能同时端住的东西有限。**

膨胀有两种形态。一种是条目变多：十条变成八十条。另一种是单条变长：一句话变成一段话，一段话变成一节。

最要命的是第三种，它不体现在字数上：**「重要」这个词通胀了。**

一开始只有三条重要，后来三十条都重要，最后每一条都不敢删。条目数没超，但优先级失效了——因为全部同级，等于没有级。这时候读者面对的是一份「什么都说了」的清单，实际能执行的是零。

一个可以算的后果：超过带宽之后，新增内容挤掉的是原来那几条的位置——净增有限，甚至为负（本文复算：带宽固定时，新增一条就挤掉一条的位置）。

判据同样是两条：**常驻的那一层，条目数有没有上限？单条有没有长度上限？** 两个上限都没有的清单，会一路长到没人读完。

膨胀还有一个伪装：**它看起来像勤奋。** 加一条比删一条容易，写得全比写得准安全。于是每一轮修订都在加，没人敢减——直到整份东西重到没人愿意打开。

## §4 腐坏三：漂移不是错，是没人报错

同一句话，存在两处。改了一处，忘了另一处。

这是结构问题：**副本之间没有一致性检查。** 内容对不对，没人比对；两处不一样，系统不报错。等到用的时候才发现口径打架，而这时候往往已经在两个地方各按各的做了半年。

漂移有三种：

| 形态 | 怎么发生 | 发现时的样子 |
|---|---|---|
| 版本漂移 | 改了一处，另一处还是旧的 | 两份都像真的，日期分不出先后 |
| 口径漂移 | 同一个词，两处定义不同 | 讨论半天，其实在说两件事 |
| 时效漂移 | 一处写了到期条件，另一处没写 | 一边已经作废，一边还在执行 |

三种里面，口径漂移不好查。因为它不表现为「不一致」，表现为「都说得通」。两个人各拿一份，各自逻辑自洽，吵起来才发现词义不同。

判据：**同一句话，有没有两个完整版？** 有，就是漂移的入口。注意是「完整版」——两处各写半句、互相指向，不算；两处都能独立读通，才算。

副本数量越多，不一致的概率越高（本文推导：每多一份，就多一条要同步的边），而且**除非有人把日期或作废标记写进去，副本不会自称旧的**。这是它比前两种腐坏更难防的地方：失忆至少会在检索那一刻撞上「找不到」；漂移连这个都没有。

## §5 三种腐坏的共同点：都不报警

把三种放在一起看，会发现一个共同结构。

| 腐坏 | 失败时的信号 | 当事人的感受 |
|---|---|---|
| 失忆 | 无 | 以为没有，其实有 |
| 膨胀 | 无 | 以为读了，其实漏了 |
| 漂移 | 无 | 以为一致，其实两版 |

三种都是**静默失败**——这是本文推导：三种形态各自的失败信号一栏都是空的，而信号为空正是它们不能被「更认真」治好的原因。

认真的人会写得更全——加速膨胀。认真的人会多留一份备份——加速漂移。认真的人会把东西记在脑子里——加速失忆（人一走就断）。

认真的方向由结构决定；方向错了，认真只是把腐坏推得更快。

所以后面这些做法，都不建立在「记住」「注意」「自觉」上。判据只有一条：**这条规矩失效的时候，有没有东西会红？** 红不了，它就只是一句愿望。

**一组对照**，取这套书自己的三处记录：

| 形态 | 现象 | 属哪种腐坏 |
|---|---|---|
| 正例 | 跨篇提另一篇时写篇号（09a、08b），不写「前文」 | 路径可定位：换个人也能顺着编号找到 |
| 反例 | 一批引用表把出处写成书外的路径，读者手里没有那份东西 | 失忆：内容在别处，路径指向书外 |
| 半例 | 一批摘要里并列七个对照名字，结语写「六个」 | 漂移：名字在、数量没对齐，两处各自都读得通 |

正例说明「编号即路径」；反例说明路径必须以读者手上的东西为准，指向书外的路径等于没有路径；半例说明漂移最会伪装——两处都自洽，只差一个数。

（三条为经验刻画，取自本系列生产记录，作一致性说明，不作独立证据。）

## §6 反直觉：越完整，烂得越快

到这里可以推出一个不太舒服的结论。

「记得越全越好」是一个直觉，它在小规模下成立，过了某个量级就反转：

- 越完整 → 条目越多 → 越过带宽 → 没人读完 → 实际可用内容趋于零（膨胀转失忆）
- 越完整 → 备份越多 → 副本越多 → 不一致概率越高（膨胀转漂移）

完整是腐坏的加速器。这一句可以按上面两条机制逐项复算：条目加一条、读物多一份、副本多一版，各自的腐坏速度都在上升。

边界要说清：**少记会直接制造失忆**——该有的没有。这里主张的是**分层**：把「完整」放在不常用的低层，把「关键」压到常用的高层。完整留给检索，关键留给人。

这一层区分是全书的地基：**腐坏治不了，只能分配。** 让每一层只承担它能承担的腐坏速度。

## §7 结语：一条判据管三种腐坏

三种腐坏，一条判据：

> **一个没参与的人，在有限的时间与有限的步数内，能不能把这件事接住？**

- 接不住，因为找不到——失忆
- 接不住，因为太多——膨胀
- 接不住，因为不知道信哪份——漂移

三种失败形态，同一句问句。后面八篇讲的判、落、写、检、长、退，都是为了让这句问句的答案是「能」。
